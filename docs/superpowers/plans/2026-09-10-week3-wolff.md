# Week 3 Wolff Cluster Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add, measure, and compare a reproducible Wolff cluster sampler.

**Architecture:** Keep cluster construction isolated in `wolff.rs`, route the existing streaming sweep through either update rule, and reuse the unmodified saved-run analysis.

**Tech Stack:** Rust 2024, Rand, existing JSONL and Plotters infrastructure.

**Spec:** `docs/superpowers/specs/2026-09-10-week3-wolff-design.md`

## Global Constraints

- Bond probability is exactly `1-exp(-2/T)` and cluster flips always accept.
- One Wolff sweep touches at least `L^2` spins through whole cluster flips.
- Default output is `artifacts-wolff/` with `algorithm="wolff"` and the 13-point critical grid.
