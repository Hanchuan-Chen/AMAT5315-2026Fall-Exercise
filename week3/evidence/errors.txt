week3 part 3 - error bars and autocorrelation times of |M|, one row per size and temperature

The grid is the same 27-temperature merged grid Part 2 used: window rows (2.00 <= T <= 2.60, 100000 measured sweeps each) win inside the critical window, coarse rows (5000 measured sweeps each) stand alone outside it.

mean_abs_M = <|M|> over the measured sweeps; n = the measured sweeps used;
naive = std(|M|, ddof=1) / sqrt(n), the error a reader gets by pretending successive sweeps are independent;
blocked = std(50 block means, ddof=1) / sqrt(50), the first 50 * floor(n / 50) sweeps cut into 50 equal blocks;
ratio = blocked / naive, how badly the naive error understates it;
tau_int = 1/2 + sum_{t>=1} rho(t) of |M| (Equation 13), truncated as the sheet describes: stop before the first negative rho(t), stop once t >= 6 * the running total, never past lag min(n // 4, 5000) - 1.
rho is evaluated by FFT in O(n log n); scripts/test_part3.py pins the FFT curve against the checker's direct sum.
