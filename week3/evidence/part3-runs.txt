(1) errors.txt: error bars and the integrated autocorrelation time of |M|

One row per size and temperature on the same 27-temperature merged grid Part 2
used (window rows inside [2.0, 2.6], coarse rows outside). tau_int is
Equation 13, summed until the lag exceeds six times the running total and
stopped early when rho(t) goes negative, never past lag min(n // 4, 5000) - 1;
rho is evaluated by FFT. The sheet's own command selects the three L = 64 rows:

  awk 'NR == 1 || ($1 == 64 && ($2 == 1.5 || $2 == 2.3 || $2 == 3.5))' evidence/errors.txt

  1.50   0.9866    0.0000431  0.0000869   2.02    1.65      5000     2.16 / 1.61
  2.30   0.4724    0.0006023  0.0184699   30.66   607.71    100000   31.16 / 669.22
  3.50   0.0287    0.0003087  0.0006154   1.99    2.26      5000     2.05 / 2.33

  pass: ratio >= 10 and tau_int of order hundreds at T = 2.3. Measured 30.66

(4) tau.png: the autocorrelation time across the transition

  L = 32: peak tau_int = 229.40 sweeps at T = 2.30; flat ends 1.62 .. 2.85
          sweeps; rise 81x; reference 190, ratio 1.21
  L = 64: peak tau_int = 607.71 sweeps at T = 2.30; flat ends 1.65 .. 2.95
          sweeps; rise 206x; reference 670, ratio 0.91

  pass: both curves flat and of order one away from T_c, L = 64 spike taller,
  and each peak within a factor of two of the reference.

  The rise from the coldest flat value to the peak is 229.40 / 1.62 = 142x for
  L = 32 and 607.71 / 1.65 = 368x for L = 64, both more than a factor of a
  hundred. tau.py prints the more conservative ratio against the largest flat
  value at either end (81x for L = 32, 206x for L = 64); either way the L = 64
  curve is the taller spike, by a factor 2.65.

  The central fit is unchanged from Part 2: T_peak(32) = 2.3495,

  the finite-size shift of about +0.008 and does not cover it.

Extension: how long is long enough

  measured sweep rate, L = 64, T = 2.3, 3 timed runs of 2000 discarded plus
  100000 measured sweeps:

    ising --update metropolis --l 64 --t-from 2.3 --t-to 2.3 --t-step 0.05 \
      --discard 2000 --measure 100000 --seed 7 --out /tmp/rate-l64

    6.49 s, 6.52 s, 6.48 s for 102000 sweeps -> 15700.5 sweeps/s (15644 to 15741)
    cross-check, the committed window-l64 ramp: 1326000 sweeps in 84.59 s
    -> 15675.6 sweeps/s, within 0.2%

  n_eff = n / (2 tau_int) = 100000 / (2 * 607.71) = 82.3 independent samples
  N     = 2 tau_int * n   = 121542000 sweeps, 1215 times the current run
  hours = N / 15700.5 / 3600 = 2.15 hours (about 2 h 9 min)
